# mc해머의 모험

[브라우저에서 게임 플레이](https://ronaldossi.github.io/mc-hammer/)

22곡·4난이도의 두 레인 리듬 게임입니다.

- 위 레인 **A**, 아래 레인 **작은따옴표(')**. 길게 누르면 롱노트입니다.
- **Esc** 또는 상단 이름·체력 영역을 눌러 일시정지합니다.
- 노트 배속은 **0.5~7배**, **0.1배 단위**로 조절합니다. 원곡의 속도와 판정 시각은 바뀌지 않습니다.
- 곡 종료 후 결과창에서 다시 도전하거나 다른 곡을 선택할 수 있습니다.
- **연속 PERFECT 3회마다 체력 1 회복**. 최대 체력까지 회복하며 GOOD·BAD·MISS가 나오면 연속 횟수가 초기화됩니다.

## 최신 업데이트

드럼·베이스·보컬·기타 반주 그룹을 로컬에서 분리해 88개 채보를 구성했습니다. 구간마다 중심 파트를 정하고 실제 반주 악센트, 지속음, 함께 울리는 음을 조합했습니다. 총 33,448개 노트, 2,118개 롱노트와 562쌍의 동시치기가 있습니다. 반주가 들리는데 오래 비던 구간을 보강했고, 새 노트에 따닥·연타·트릴·축연타를 난이도에 맞게 배치했습니다. 조용한 쉼은 유지합니다.

달려라 모코코즈!의 노트 수는 EASY 191 / NORMAL 273 / HARD 442 / NIGHTMARE 523입니다. 캐릭터 달리기·가드·메뉴 애니메이션은 30% 빨라졌으며, 타격음에는 사용자가 제공한 소리의 뒤쪽 ‘뿅’ 부분을 짧게 잘라 넣었습니다.

음악은 기존 원곡 그대로 재생합니다. 분리된 악기는 채보 분석에만 사용하며 웹에 분석용 음원을 추가하지 않았습니다. [Demucs](https://github.com/facebookresearch/demucs)와 [MELODIA](https://essentia.upf.edu/reference/std_PredominantPitchMelodia.html)를 이용한 자동 분석이므로 완벽히 분리된 스튜디오 원본이나 수작업 악보로 해석하지 않습니다.

88개 채보의 전곡 PERFECT·0 MISS 재생, 배속 불변성, 실제 타격음과 연속 PERFECT 회복을 포함해 소스 검사 1,447개를 통과했습니다. 서머너 긴 목 이스터에그 확률은 50%이며 기존 판정 허용 범위는 유지합니다.
