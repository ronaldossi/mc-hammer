# mc해머의 모험

[브라우저에서 게임 플레이](https://ronaldossi.github.io/mc-hammer/)

22곡의 OST와 영상을 배경으로 플레이하는 두 레인 리듬 게임입니다. EASY, NORMAL, HARD, NIGHTMARE를 선택할 수 있습니다.

- 위 레인: **A**, 아래 레인: **작은따옴표(')**
- 탭 노트는 짧게 누르고, 롱노트는 끝까지 유지합니다.
- **Esc** 또는 상단 이름·체력 영역을 눌러 일시정지합니다.
- 곡 종료 후 결과창에서 다시 플레이하거나 음원 선택으로 돌아갑니다.

## 주선율 채보 업데이트

22곡 전체 약 65분의 오디오에서 주선율의 음 높이, 음 시작점, 반복음과 지속음을 자동 추출해 88개 채보를 재구성했습니다.

- 음의 상대적 높낮이를 위·아래 레인에 반영하고, 필요한 곳에는 연주 가능한 교대 운지를 적용했습니다.
- 실제 반복음을 연타로, 안정적으로 이어지는 음을 롱노트로 표현합니다.
- EASY는 프레이즈의 핵심 음을 고르고, 상위 난이도는 짧은 음과 반복음을 더 많이 포함합니다.
- 음 시작점은 분석된 실제 시각을 사용하며, 음악 속도와 원본 영상은 동일합니다.
- 달려라 모코코즈!의 노트 수는 EASY 144 / NORMAL 205 / HARD 281 / NIGHTMARE 334입니다.
- 이전 웹 전용 50ms 판정 확장을 되돌렸습니다. PERFECT/GOOD/BAD의 각 방향 허용치는 EASY 180/280/340ms, NORMAL 150/240/300ms, HARD 140/215/260ms, NIGHTMARE 130/195/230ms입니다.
- 서머너 긴 목 이스터에그 확률은 매 판 50%입니다.

분석은 [MELODIA 주선율 추정 알고리즘](https://essentia.upf.edu/reference/std_PredominantPitchMelodia.html)을 사용해 로컬에서 수행했습니다. 복잡한 합주 구간의 선율 선택은 자동 추정에 따른 불확실성이 있습니다.

88개 채보의 자동 전곡 입력 검사와 판정 경계, 결과창 검사를 통과했습니다.

## 배포 관리

`site` 폴더가 공개 웹 파일입니다. **Settings → Pages → Source**는 **GitHub Actions**이며, **Actions → Deploy game to GitHub Pages → Run workflow**로 게시합니다.

새 버전이 보이지 않으면 Ctrl+F5로 새로고침하세요. 첫 실행에는 엔진과 게임 데이터 다운로드 시간이 필요합니다.
## 공백 연결 업데이트

주선율의 기존 노트와 롱노트를 보존하고, 긴 공백에 실제 반주의 음 시작점으로 연결 노트를 추가했습니다. 음량이 매우 낮거나 뚜렷한 공격음이 없는 부분은 휴식으로 남깁니다. EASY는 성기게, 상위 난이도는 더 촘촘하게 연결합니다.

달려라 모코코즈!의 현재 노트 수는 EASY 144 / NORMAL 205 / HARD 281 / NIGHTMARE 334입니다. 전체 88개 채보에 연결 노트 5863개를 추가했으며, 전곡 자동 입력 검사를 통과했습니다.
