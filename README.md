# mc해머의 모험

[브라우저에서 게임 플레이](https://ronaldossi.github.io/mc-hammer/)

22곡의 OST와 영상을 배경으로 플레이하는 두 레인 리듬 게임입니다. EASY, NORMAL, HARD, NIGHTMARE를 선택할 수 있습니다.

- 위 레인: **A**, 아래 레인: **작은따옴표(')**
- 탭 노트는 짧게 누르고, 롱노트는 끝까지 유지합니다.
- **Esc** 또는 상단 이름·체력 영역을 눌러 일시정지합니다.
- 곡 종료 후 결과창에서 같은 곡을 다시 플레이하거나 음원 선택으로 돌아갈 수 있습니다.

## 이번 업데이트

- 실제 음악·영상의 종료 신호로 결과창을 열도록 보완했습니다.
- 빈 레인의 너무 이른 입력이 나중 노트를 소모하던 문제를 수정했습니다.
- HARD와 NIGHTMARE에 짧은 2연타·3연타, 레인 전환 연타, 교차 연타 묶음을 추가했습니다.
- 달려라 모코코즈!는 HARD 246개, NIGHTMARE 443개 노트입니다.
- 기존 웹 전용 판정 여유 50ms와 개구리 탭 아이콘을 유지합니다.

패턴 구성을 위해 [osu!mania 매핑 가이드](https://osu.ppy.sh/wiki/en/Guides/osu%21mania_mapping_guide)의 연타·교차 패턴 설명을 참고했습니다. 채보는 제공된 곡의 분석된 박자에 맞춰 이 게임용으로 구성했습니다.

## 배포 관리

`site` 폴더가 공개 웹 파일입니다. 저장소 **Settings → Pages → Source**는 **GitHub Actions**이며, **Actions → Deploy game to GitHub Pages → Run workflow**로 게시합니다. 저장소에 변경을 올리는 것만으로 자동 게시되지는 않습니다.

새 버전이 보이지 않으면 Ctrl+F5로 새로고침하세요. 첫 실행에는 엔진과 게임 데이터 다운로드 시간이 필요합니다.
